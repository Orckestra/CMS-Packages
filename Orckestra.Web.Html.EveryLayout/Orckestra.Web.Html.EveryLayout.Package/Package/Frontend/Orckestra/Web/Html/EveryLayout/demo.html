EveryLayout functions demo

Here are some fairly basic examples that were initially created in C1 with the functions available in this package. Make sure to play around with them, mix them together, and you'd be surprised by what kind of layouts you can achieve.

They were mostly based on a book available at https://every-layout.dev/, which I highly recommend to anyone who likes CSS.
